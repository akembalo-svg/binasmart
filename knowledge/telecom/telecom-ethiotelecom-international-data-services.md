# International Data Services

L3 MPLS (Multi Packet Label Switching)
An Ethernet based point-to-multipoint VPN that allows a service provider to connect geographically spread LAN networks to each other over its MPLS core.

L2 VPLS (Virtual private LAN service)
A type of communication used within a network. It is used to send data and network traffic along the most efficient routes, which may be predetermined and are communicated using labels.

IPLC (International Private Leased Circuit)
A point-to-point private line used to communicate between offices that are geographically dispersed throughout the world. It can be used for Internet access, business data exchange, video conferencing, and any other form of telecommunication.
