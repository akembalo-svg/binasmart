Package extenders main points:

- Voice package extender can only extend voice and Voice plus data packages.

- Data package extender can only extend Data and Voice plus data packages.

- The package extender will be extended only both weekly and monthly packages.

- The extension applies for both self-purchased and gifted packages.

- The extended volume will be added to the new package extender volume with the new validity time (5 days).

- The package extender package is only available for self-purchase, and not for gift purchases.

- The package extender package cannot be applied to the bonus package.

- The extender package is transferable and convertible, but the original or extended package keep the existing business rules.

- All prices include 5% Excise Tax and 15% VAT.
