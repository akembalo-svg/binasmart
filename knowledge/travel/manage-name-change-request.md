## General Terms and Conditions

A name change is allowed under the following circumstances, provided you submit supporting documents (Like, a marriage certificate ,Deed Poll or passport copy) and a service charge of USD 50.00:

- If the reservation was made under the husband's family name instead of the maiden name (or vice versa).
- Name Changes Not Related to Marriage Passengers who have legally changed their names through a Deed Poll for different reasons, independent of marriage, must submit the Deed Poll document as evidence of the official name change. This option should be added together with changing due to Marriage.
- If you have multiple given names and need to add a second name (when only the first name was entered during booking).
- A name change from Mr. X to Mr. Y is not allowed, except in the cases outlined above.
- Minor errors in the first name, last name, or middle name (such as transposition or up to three-letter changes) can be corrected, allowing the original ticket to be used for payment of the new ticket.
- A change in title (e.g., from Mr. to Mrs./Ms., or from Mrs. to Ms.) can be requested.
- Tickets purchased through travel agencies are not eligible for name changes.
