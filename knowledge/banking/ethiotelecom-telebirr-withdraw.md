If you're a non-telebirr user you will receive a voucher PIN via SMS and you can take the PIN to a nearby telebirr agent or Ethio telecom's shop to withdraw your money anytime.

#
How to Withdraw Cash Using telebirr

##
Withdraw Cash Through an Agent or Shop

- Visit nearby agent or Ethio telecom shop

- Dial *127# or login to telebirr mobile app

- Select "Withdraw Cash" from the menu

- Withdraw cash using the following options:

- Agent ID: Enter the agent ID, amount, and PIN, then confirm

- Voucher: Generate voucher code, provide it to the agent, and confirm

- QR Code: Scan QR, enter amount and PIN, then confirm

##
For Non-Registered Telebirr Users

If you are not registered for telebirr but have received a cash transfer:

- Show voucher code you received via SMS and proof of identity to the agent

- The agent checks the voucher and provides you cash in return

## How to withdraw cash using telebirr

- Visit nearby agent or Ethio telecom shop
- Dial *127# Or login to telebirr mobile app
- Select ‘Withdraw Cash’ from the menu then withdraw cash by using the below options:
- Withdraw cash using Agent ID
- Enter agent ID from which cash is to be collected.
- Enter the amount of money to be drawn
- Enter PIN
- Confirm the amount to be withdrawn and receive your money.

- Withdraw cash by Voucher:
- Select ‘Withdraw cash by voucher’ from the menu
- Generate voucher code
- Provide the voucher and amount required to the agent
- Confirm transaction
- Receive your money from the agent

- Withdraw cash by scanning QR code and enter amount:
- Select Scan QR from
- Enter the amount of money to be drawn
- Enter PIN
- Confirm the amount to be withdrawn
- Receive your money from the agent

- Show voucher code you received via SMS and proof of identity to the agent
