ጉምሩክ ቀረጥCustoms & Import Duty

0–35% · CIF · ECC · 5 ታክሶች
ወደ ኢትዮጵያ ዕቃ ማስገባት ይፈልጋሉ? የ import ቀረጥ እንዴት እንደሚሰላ — በ CIF ላይ ያሉት 5 ታክሶች (ጉምሩክ ቀረጥ፣ ኤክሳይዝ፣ VAT፣ ሰርታክስ፣ withholding)፣ HS code እና እንዴት መክፈል — ግልፅ መመሪያ።
🖼️ ናሙና ገላጭ ምስል (illustrative)
0–35%ጉምሩክ ቀረጥ
CIFላይ ይሰላል
5ታክሶች
ECCይሰበስባል

📦 የጉምሩክ ቀረጥ ምንድን ነው?

ወደ ኢትዮጵያ ዕቃ ሲያስገቡ በኢትዮጵያ ጉምሩክ ኮሚሽን (ECC) በኩል ታክስ ይከፍላሉ። የጉምሩክ ቀረጥ (customs duty) የሚሰላው በCIF ዋጋ (የዕቃው ዋጋ + ኢንሹራንስ + ማጓጓዣ) ላይ ነው፣ እንደ ዕቃው የHS tariff code ይለያያል። ቀረጡ ከ0% እስከ 35% ያሉ 6 ደረጃዎች (0%, 5%, 10%, 20%, 30%, 35%) አሉት።

In English: when you import goods into Ethiopia you pay tax through the Ethiopian Customs Commission (ECC). Customs duty is calculated on the CIF value (goods + insurance + freight) and varies by the item's HS tariff code, across six bands: 0%, 5%, 10%, 20%, 30%, 35%.

🧮 5ቱ የ import ታክሶች

የንግድ import በተከታታይ (compounding) እስከ 5 ታክሶች ሊጣልበት ይችላል — ሁሉም በ ECC ይሰበሰባሉ፦

#ታክስመጠን
1የጉምሩክ ቀረጥ (Customs Duty)0–35% (እንደ HS code)
2ኤክሳይዝ (Excise) — ለቅንጦት ዕቃ10–100% (እንደ ዕቃው)
3ተ.እ.ታ (VAT)15%
4ሰርታክስ (Surtax)10%
5ተቀናሽ ግብር (Withholding)3% በ CIF

📌 ታክሶቹ በቅደም ተከተል ተደራርበው ይሰላሉ (withholding ግን አይደራረብም)። ሁሉም በ import ጊዜ ይከፈላሉ። ትክክለኛውን በ ECC የታክስ ካልኩሌተር ያስሉ።

In English: a commercial import can carry up to five taxes collected by ECC, applied in a compounding sequence — customs duty (0–35%), excise (10–100% on luxury goods), VAT (15%), surtax (10%), and withholding (3% on CIF, not compounding). All are payable at import; use the ECC calculator for the exact figure.

📌 ግምታዊ ስሌት ነው (VAT 15%፣ ሰርታክስ 10%፣ withholding 3%)። ትክክለኛውን በECC ካልኩሌተር ያረጋግጡ።

📋 ቀረጥ እንዴት ማስላት/መክፈል

1. HS code ይለዩ

የዕቃዎን Harmonized System (HS) tariff code ይለዩ — ቀረጡን ይወስናል።

2. CIF ዋጋ ያስሉ

የዕቃ ዋጋ + ኢንሹራንስ + ማጓጓዣ = CIF።

3. 5ቱን ታክሶች ያስሉ

የ ECC customs tax calculator ይጠቀሙ — ትክክለኛውን ድምር ያገኛሉ።

4. በ import ጊዜ ይክፈሉ

ታክሶቹ ዕቃው ሲገባ ይከፈላሉ — በ ECC/ጉምሩክ ውክልና (agent) በኩል።

5. ዕቃውን ያስወጡ (Clear)

ክፍያ ከተፈጸመ በኋላ ዕቃዎን ከጉምሩክ ያስወጣሉ።

⚖️ ሕጋዊ መሠረት · Legal basis

የጉምሩክ አዋጅ ቁጥር 859/2006 (Customs Proclamation No. 859/2014)፣ በአዋጅ ቁጥር 1425/2018 (Proclamation No. 1425/2026) እንደተሻሻለ — የፌዴራል ነጋሪት ጋዜጣ ቁጥር 42፣ ከሐምሌ 16/2018 (23 July 2026) ጀምሮ ተፈጻሚ።

በ2026 ማሻሻያ የተለወጡ፣ ለዚህ ገጽ አንባቢ የሚጠቅሙ ነጥቦች፦

  • ከፊል መልቀቅ — ቀረጡን በሙሉ አንድ ጊዜ መክፈል ካልቻሉ፣ ለተከፈለበት ክፍል ብቻ ዕቃ ይለቀቃል (አንቀጽ 25(5))።
  • የመጋዘን ገደብ — በባሕር/በየብስ 45 ቀን፣ በአየር 30 ቀን፤ ካለፈ ወደ መንግሥት መጋዘን ይዛወራል፣ ከመሸጡ በፊት ከፍለው መውሰድ ይችላሉ (አንቀጽ 51)።
  • የዋጋ ዳታቤዝ ዝቅተኛ ዋጋ አይደለም — ለስጋት ግምገማ ብቻ ነው፤ የገለጹትን ዋጋ በራሱ አይተካም (አንቀጽ 89(5))።
  • ዋጋዎ ሲቀር — በጽሑፍ ምክንያት የማግኘትና ከመጨረሻ ውሳኔ በፊት መልስ የመስጠት መብት አለዎት (አንቀጽ 99(3))።
  • የምንዛሪ ተመን — ዲክላሬሽኑ ተቀባይነት ባገኘበት ቀን የብሔራዊ ባንክ አመላካች ተመን (አንቀጽ 101)።
  • ተመላሽ — ዲክላሬሽኑ ከተዘጋ በአንድ ዓመት ውስጥ መጠየቅ አለበት (አንቀጽ 123(2))።
  • ይግባኝ — የተከራከረው ቀረጥ 50% ካልተከፈለ ይግባኝ አይቀበልም (አንቀጽ 155(2))።

ሙሉ ማብራሪያ፦ አዲሱ የጉምሩክ አዋጅ 1425/2018 — አስመጪዎች ማወቅ ያለባቸው → · ተዘምኗል 5 Sep 2026

❓ ተደጋጋሚ ጥያቄዎች

የጉምሩክ ቀረጥ እንዴት ይሰላል?

በ CIF ዋጋ (ዕቃ + ኢንሹራንስ + ማጓጓዣ) ላይ በ HS code መሰረት ከ0% እስከ 35% ይጣላል።

ስንት ታክሶች አሉ?

እስከ 5፦ ጉምሩክ ቀረጥ (0–35%)፣ ኤክሳይዝ (10–100%)፣ VAT (15%)፣ ሰርታክስ (10%)፣ withholding (3%)። በተከታታይ ይደራረባሉ።

ትክክለኛውን ቀረጥ የት አስላለሁ?

በ ECC customs tax calculator (ecc.gov.et)።

VAT በ import ላይ ይጣላል?

አዎ — 15% በአብዛኛው import ላይ (ነጻ ካልተደረገ)። ስለ VAT ተጨማሪ /vat-registration-ethiopia ይመልከቱ።
