Connect in one minute

🟢 Claude (claude.ai)

  1. Open Customize → Connectors and click Add (Add custom connector).
  2. Name: BinaSmart. URL: https://bina.et/mcp. Continue.
  3. Authentication: None (detected). Click Add, then Connect.
Claude Code: claude mcp add --transport http binasmart https://bina.et/mcp

⚫ ChatGPT

  1. Settings → Security and login → turn on Developer mode.
  2. Open Plugins (left menu) → Create app.
  3. Name BinaSmart, Server URL https://bina.et/mcp, Authentication No Auth, tick “I understand”, Create.
  4. In a chat, press +, choose BinaSmart, then Connect the first time.
BinaSmart is also submitted to the ChatGPT app directory; once approved, no developer mode is needed.

🔵 Perplexity (Pro, Max or Enterprise)

  1. Profile → Settings → Connectors.
  2. + Custom connector → Remote.
  3. Paste https://bina.et/mcp, no credentials, save.

🔴 Gemini

  1. gemini.google.com → Settings → Connected apps.
  2. Under Custom apps for Spark, paste https://bina.et/mcp.
Google currently allows custom apps only for Gemini Ultra subscribers in the US. BinaSmart is ready the day Google opens it wider.

For developers

BinaSmart is a public Model Context Protocol server: Streamable HTTP, no authentication, 9 tools with read-only and write annotations, rate-limited. Documentation and health check at bina.et/mcp. Booking is limited per phone number; ride bookings from assistants land in the same dispatch queue as the website.
